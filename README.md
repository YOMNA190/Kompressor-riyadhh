# Kompressor Riyadh

A compressor-services website for Riyadh with a service-led landing-page structure and direct customer contact journeys.

## Overview

A Riyadh compressor-services website built with React, TypeScript, Vite, and Tailwind CSS.

## Highlights

- Responsive service website
- Local-business content structure
- Direct contact and conversion touchpoints
- Vite-based production workflow

## Tech stack

React, TypeScript, Vite, Tailwind CSS, ESLint

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown by the development server. For a production build:

```bash
npm run build
npm run preview
```

## Available scripts

| Script | Command |
|---|---|
| `dev` | `vite --host` |
| `build` | `vite build` |
| `start` | `NODE_ENV=production node dist/index.js` |
| `preview` | `vite preview --host` |
| `check` | `tsc --noEmit` |
| `format` | `prettier --write .` |

## Project structure

The application code lives in `src/`, static assets are served from `public/`, and the project configuration is kept at the repository root.

## Environment variables

Do not commit credentials or production secrets. Copy the example environment file when one is provided and keep local secrets in `.env.local`.
